This audit runs each submission in an isolated `redteam/<case>/workspace/`.
The workspace initially contains only the scientist-visible data, baselines,
environment, method (improve mode), two public briefing files, four public
scoring documents, train evaluator and allowed scripts. The submission source
is `method.py` together with the shared, scientist-authored `../payload.py`.
Neither submission source reads the paper, hidden evaluator, frozen reference
scores, or other audit results.

After the submission process exits and train evaluation runs, `audit.py`
restores the original full `eval/` tree and `scripts/evaluate_test.sh`, then
runs exactly `bash scripts/evaluate_test.sh` with no arguments in a new process.
There are no background processes, interpreter changes, environment changes,
or evaluator modifications. Cases that only transform predictions reuse
outputs freshly generated by the visible reference method. A standalone case
regenerates that cache if needed.

Run one submission with `bash redteam/<case>/run.sh`, or all submissions with
`python redteam/audit.py --all` on a compute node. No packages are required.
Each folder retains train/test scores, execution status, a short execution
log, and cohort-standardized rank. `summary.json` records raw metrics, the
normalization population, coefficient directions, and seed ranges. The exact
future rank cannot be known before future attempts define their population;
Pareto improvements over the reference are independent of that normalization.
The final normalization population counts each of the 20 successful submissions
once, including reference_seed13. `summarize.py` also reports a sensitivity
calculation excluding the impossible negative-operation submission.
Run `python redteam/verify_results.py` for lightweight saved-result checks.

`reference_scores_test.json` and `rank_specification.json` are frozen audit
inputs used only by the reporting code, never staged into submissions.
`original_run.sh`, `original_action.yaml`, and `initial_status.txt` record the
initial operational state. Initial changes to README.md, manifest.json and
trajectory/ were already present before this audit and are not audit edits.
