The all-wrong-ID and entirely empty submissions do not compensate for task failure through cheap cost or perfect answer F1 in this cohort. However, the ID-only shortcut establishes that a system returning no evidence can score above the reference through the other metrics; there is no required text-validity or minimum-utility gate. The largest shortcuts require no genuine retrieval improvement and can exceed the honest fix by a wide margin. The scored cost constraint is a submitted number, not a measurement of actual computation.

Population normalization does not remove these issues. Including the impossible −10¹² operation count makes the operation standard deviation approximately 2.18×10¹¹, suppressing honest cost differences. Removing only that outlier yields an operation standard deviation of 4,143.10. Then the honest fix scores +3.110024, the one-bit ablation −1.290484, the seed range is 2.132503, and the omitted-operation shortcut scores +0.018026. The main findings and gain directions persist. Every submission was staged using only scientist-visible inputs. Improve-mode shortcuts that transform reference outputs first use the actual visible method's newly generated outputs; they do not read the frozen reference scores or a supplied hidden artifact. Label/generator/empty-output submissions need no existing method. After the submission exits, the harness restores the original `eval/` tree and test script and invokes exactly `bash scripts/evaluate_test.sh` with **no arguments** in a fresh process. All successful runs score all 36 test questions. The single enclosing compute container was reused for efficiency; submissions share no persistent processes, evaluator changes, or Python-environment changes. The harness's allowed staging, subprocess boundaries, and original evaluator hashes are recorded in [audit.py](redteam/audit.py) and each `status.json`.

The next iteration should hide and independently load unreconstructable test labels, restore immutable scoring data/artifacts as well as evaluator code, derive evidence text from validated entry IDs, and measure or verify nonnegative search work. A larger, genuinely varied task must resist exhaustive lexical matching. Reference results should cover multiple fixed seeds. Utility/validity requirements should be enforced before efficiency tradeoffs are ranked. No such fixes were applied in this audit; all source and scoring files outside the audit remain as they were before it, apart from the required action control file.
